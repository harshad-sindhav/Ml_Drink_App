# ML Drink App

## Project Overview

ML Drink App is a machine learning project built with Python and Streamlit. It provides a web-based interface for users to interact with the application's functionality.

This project demonstrates the use of Python, machine learning concepts, and web application development.

## Features

- Interactive web interface using Streamlit
- Python-based application
- Machine learning project structure
- User-friendly input interface
- Web application deployment using Streamlit Community Cloud

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Git and GitHub

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/harshad-sindhav/Ml_Drink_App.git
```

### 2. Open the project folder

```bash
cd Ml_Drink_App
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 6. Run the Streamlit application

```bash
streamlit run app.py
```

If `drink_app.py` is the actual main application file, use:

```bash
streamlit run drink_app.py
```
